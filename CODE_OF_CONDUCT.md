# Code of conduct

Be respectful and keep discussion about the work. Disagree with the code or the idea, not the person.

- Assume good faith and be patient with newcomers.
- No harassment, discrimination or personal attacks.
- Give specific, kind feedback and accept it the same way.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, email heykavofficial@gmail.com.
